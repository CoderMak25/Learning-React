# Learning React

A collection of small React + Vite practice projects.

## Projects

### 1) amazonCards
A simple product card UI practice app.

- Source: `amazonCards/src`
- Entry file: `amazonCards/src/main.jsx`

### 2) boardGame
A board game style UI practice app (includes a Ludo board component).

- Source: `boardGame/src`
- Entry file: `boardGame/src/main.jsx`
- Key component: `boardGame/src/LudoBoard.jsx`

### 3) todoList
A basic todo list practice app.

- Source: `todoList/src`
- Entry file: `todoList/src/main.jsx`
- Key component: `todoList/src/TodoList.jsx`

## Tech Stack

- React
- Vite
- ESLint

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm

### Install dependencies

Run this command in each project folder (`amazonCards`, `boardGame`, `todoList`):

```bash
npm install
```

### Run a project

Open a terminal in the project you want to run, then:

```bash
npm run dev
```

Vite will print a local URL (usually http://localhost:5173).

## Build for production

In any project folder:

```bash
npm run build
```

## Preview production build

In any project folder:

```bash
npm run preview
```
